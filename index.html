📖 使用说明

1️⃣ 数据更新：网页读取本地 data.js（由「更新数据.bat」从腾讯文档抓取）。每天打开电脑运行一次，或配置「设置每日自动更新.bat」实现全自动。

2️⃣ 今日新开：顶部卡片展示「更新日期 = 今天」的新开公司，点击「去投递」直达官网。

3️⃣ 投递状况：点击「未投递 / 已投递」按钮切换。

4️⃣ 测评情况：点击「未测评 / 已测评」按钮切换，点「🔗 测评链接」填写测评网址和截止日期。

5️⃣ 面试情况：点击「一面 / 二面 / 三面」按钮弹出面试时间安排输入框，填写日期时间（可加备注），保存后显示在行内；再次点击可修改或清除。点小圆点标记该轮已完成。

6️⃣ Offer 情况：点击「进行中 / 已Offer / 挂了」循环切换。

7️⃣ 数据保存：所有状态自动保存到浏览器 localStorage，关闭页面不丢失；换浏览器/清缓存会丢失。

8️⃣ 筛选：支持按关键词、更新日期、批次、行业、状态组合筛选。搜索不到的公司可直接「创建投递公司」。
